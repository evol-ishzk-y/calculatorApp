## 💻 プロジェクト概要
C#の学習を目的として作成をしたWindows Formsの電卓のアプリケーションです。
数字ボタンや小数点のボタンを実装しており、四則演算ボタンに加え百分率ボタン、符号反転ボタンなど基本的な機能を兼ね備えたものを作成しました。
また、ユーザーが誤った入力をしてもall_clearボタンやBackSpaceボタンを実装しており文字を消すパターンを二通り用意しています。
コードの構造に気を配り、数字にはnumButton_Clickメソッド、演算子ボタンにはoptionButton_Clickメソッドとしてまとめ、コードの保守性を意識した作りにしました。

参考サイト：https://kintame.site/c-calculator/

## 💡 工夫した点・技術的アピール
1．	役割を分け、わかりやすい構造に  
  数字のボタン、演算子のボタンと役割ごとにメソッドを作り、コードの保守性を意識した作りにしました。  
2．	入力チェックで意図しないものは受け付けない仕組みに  
ユーザーが間違った入力をしても受け付けない仕組みにしました。  
  例えば小数点を一度入力していたら二回目は受け付けない。0の時に0を入力しても受け付けない処理などを実装しました。  
3．現在入力している演算子を表示
  演算子を入力したら左上にどの演算子を入力したのか表示させて見やすくしたつくりにしました。

## 🔮 今後の展望
挑戦したい機能
１．キーボードでの入力にも対応する  
現在はマウスカーソルでの入力に限られているので、キーボードでの入力を可能にし、入力時のパターンを増やす。  
２．計算履歴のログを表示  
「＝」ボタンを押した際に、どのような計算をしたかのログを表示させる。  
３．見た目のデザインを修正  
文字の大きさやフォントなどを文字をより見やすくする。カーソルを合わせたときに色が変わる設定など。
